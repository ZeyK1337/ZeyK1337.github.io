The original robot-seminar homepage is retained with a portfolio link. ZIPs preserve internal project folders; selected notebooks and reports can be viewed directly. The FIT5196 collection is a members 1-2 working version, not the finished group submission. The FIT5147 Shiny app found inside the FIT5145 folder is labelled as supplementary.

Large raw datasets, row-level survey/commerce exports, course handouts, redundant archives and session caches are excluded. Public notebooks have cleared outputs and normalised student identifiers. Original PDFs/video retain original attribution. Data dependencies and execution limits are documented for each collection. Historical results are not newly reproduced for this publication.

No blanket open-source licence is applied to third-party coursework or group contributions.
