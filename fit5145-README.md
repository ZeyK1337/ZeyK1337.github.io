# FIT5145 | Data exploration & predictive analysis

R / R Markdown work in three themes:

1. **NBA injury risk**: proposal, exploratory analysis, report, slides and local public sports datasets.
2. **Ireland news**: cleaning, engagement analysis, time trends, and comparison with World Bank internet-use and GDP indicators.
3. **Property and forum analysis**: Victorian property exploration and prediction; comparison of forum-label classifiers.

Open the relevant `analysis.Rmd` in RStudio, install the packages used in its setup chunks, and set the working directory to that analysis folder. This publication does not claim every original analysis is fully reproducible from the archive alone.

The large `ireland_news.csv`, property datasets, and record-level forum datasets are not distributed. Supply your authorised originals using the filenames referenced in the R Markdown. No R workspace caches or session history are included.

## Supplementary app found in the same local folder
`supplementary-FIT5147-diet-dashboard/` contains a diet-and-health Shiny dashboard. Its own original README labels it **FIT5147**; it is included as a separately labelled supplementary project, not relabelled as FIT5145. See its README for dependencies and `shiny::runApp()` instructions. GitHub Pages hosts static content; the R Shiny backend must run separately.

Original reports retain their attribution. Code/notebook identifiers were normalised in this public copy; modelling methods were not changed or rerun.
