# FIT5137 | MonCity dimensional warehouse & analytics

Report-led case study covering operational data profiling, cleaning, two dimensional schema designs, Oracle implementation, reconciliation, and Power BI analysis.

The report documents 10,000 cleaned bookings, 1,001 maintenance events and 993 valid accidents reconciled to the warehouse. It discusses bridge tables and allocation weights for many-to-many relationships.

The selected local folder contained a report and presentation video, with SQL examples embedded in the report. It did not contain standalone SQL deployment scripts or a Power BI `.pbix` file. The portfolio does not imply those files are included or that the database has been redeployed.

The report is supplied as an original authored artefact and retains its original author/student attribution. The presentation video is separately available from the portfolio page.
